Connect Website / API Integration

Collect customer leads directly from any website, landing page, or frontend form

Dual Authentication Required for All API Calls:

  • SECRET_KEY: Your master secret configured on Render (X-Secret-Key).
  • User API Key: Generated under Users & API Keys (X-API-Key).

When leads are submitted with a User's API key, their platform name is automatically recorded in the From column.

API Endpoint (CORS Enabled)

POST https://your-domain.onrender.com/api/customers

Only phone is strictly required. Name, email, address, landmark, city, state, pincode, and profile are optional.

JavaScript / Frontend Website Code

// Collect customer lead from website/app
async function submitCustomerLead() {
  const response = await fetch('/api/customers', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'X-Secret-Key': 'YOUR_SECRET_KEY',   // Master SECRET_KEY (REQUIRED)
      'X-API-Key': 'YOUR_USER_API_KEY'     // User/Platform API Key (REQUIRED)
    },
    body: JSON.stringify({
      phone: "+91 9876543210", // REQUIRED: only phone is mandatory
      name: "Rohan Sharma",    // optional
      email: "rohan@example.com", // optional
      address: "123 Green Park",  // optional
      landmark: "Near Metro",     // optional
      city: "Jaipur",             // optional
      state: "Rajasthan",         // optional
      pincode: "302001",          // optional
      profile: "Interested in service" // optional
    })
  });
  const data = await response.json();
  console.log('Lead submitted:', data);
}
