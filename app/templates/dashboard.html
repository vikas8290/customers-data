Website Data Collection API

Collect customer data directly from any website

API Endpoint (Requires SECRET_KEY)

POST /api/customers

CORS is enabled. Pass your configured SECRET_KEY via X-Secret-Key header, Bearer token, or secret_key parameter.

JavaScript / Website Form Code

// Collect customer data from website
async function submitCustomerData() {
  const response = await fetch('/api/customers', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json',
      'X-Secret-Key': 'YOUR_SECRET_KEY' // REQUIRED
    },
    body: JSON.stringify({
      phone: "+91 9876543210", // REQUIRED
      name: "Rohan Sharma",
      email: "rohan@example.com",
      address: "123 Green Park",
      landmark: "Near Metro",
      city: "Jaipur",
      state: "Rajasthan",
      pincode: "302001",
      profile: "Interested in service",
      from: "website" // Source tracker
    })
  });
  const result = await response.json();
  console.log('Customer saved:', result);
}
